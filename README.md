# Tetrachrome

Упаковщик текстурных каналов для игровых художников: собирает до четырёх
grayscale-карт (Metallic, AO, Roughness, Smoothness, Detail Mask…) в RGBA-каналы
одной текстуры по соглашениям Unity (URP, HDRP), Unreal и Godot.

- Windows 10+ x64, один `.exe` без установщика
- Rust + egui (eframe); обработка на CPU, в линейном пространстве
- Пресеты движков; свои пресеты — в `presets.json` рядом с exe (если файл там есть) или в `%APPDATA%\Tetrachrome`
- Экспорт PNG / TGA / TIFF, 8 или 16 бит

## Что умеет

- Карты бросаются в окно или на карточку канала; по суффиксу имени (`_Metallic`, `_AO`…) сами встают в свой канал
- При смене пресета карты следуют за ролями; Smoothness собирается из инвертированной Roughness и наоборот
- У каждого канала: какой канал исходника читать (R/G/B/A/яркость), инверсия, sRGB → linear, заливка без картинки
- Предпросмотр RGBA на шахматке с масштабом и сдвигом, отдельные каналы, точные значения пикселя под курсором
- Разные размеры исходников: масштаб к большему, к меньшему или свой размер
- Пакетный режим: папка карт → материалы по именам → упаковка всех, с прогрессом и журналом
- Отмена/повтор (Ctrl+Z / Ctrl+Y), Ctrl+O, Ctrl+E, Ctrl+S, F5 — перечитать исходники

## Сборка

```
cargo build --release
```

Результат — `target\release\tetrachrome.exe`. Тестовые карты для проверки:
`cargo run --example samples -- <папка>`.
