# Значок Tetrachrome

Буква T из четырёх квадратов — «тетра»: ряд R-G-B цветами каналов программы (`#FF5F6D`, `#45D48A`,
`#4F9DFF`) и ножка-альфа с шахматкой (`#F1F3F8` / `#A7AEBD`), как в предпросмотре, на плитке цвета
тёмной бирюзы `#0F3532 → #041312` (бирюза — цвет программы в семье Anvil). Выбор владельца 30.09.2026
(вариант 8 «Крупнее»).

| Файл | Что это |
|---|---|
| `tetrachrome.svg` | Полный значок: квадраты 272, зазор 30, радиус 42. Источник для 64 px и крупнее |
| `tetrachrome-small.svg` | Для мелких размеров: зазор 36, радиус 32. Источник для 16–48 px |
| `tetrachrome-{16,24,32,48}.png` | Из `tetrachrome-small.svg` |
| `tetrachrome-{64,128,256,512}.png` | Из `tetrachrome.svg` |
| `tetrachrome.ico` | Кадры PNG 16, 24, 32, 48, 64, 128, 256 — значок exe |

PNG и `.ico` не правятся руками — их собирает одна команда из SVG (нужен `resvg`, `scoop install resvg`):

```powershell
powershell -File scripts\render-icon.ps1
```

Повторный запуск без правок SVG даёт те же файлы.

**Где значок используется.** Значок exe — `tetrachrome.ico` (`build.rs`, `winresource`); значок окна и
панели задач — `tetrachrome-256.png` (`src/icon.rs`); знак в шапке и в «О программе» рисуется кодом
(`src/ui/mark.rs`) по геометрии `tetrachrome-small.svg` — цвета каналов там не зависят от темы окна.

**Центровка.** Знак сдвинут на глаз: у T три квадрата сверху и один снизу, поэтому по границам он
кажется опущенным. Сдвиг записан в `transform` группы знака: (1.3, −14.3) для полного и (1.3, −17.4)
для мелкого.
